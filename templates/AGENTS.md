# Codex Project Instructions

This project uses the global `project-journal` skill for project continuity.

At the start of a new conversation:

1. Read `PROJECT_MEMORY.md`.
2. Read the latest Obsidian project log listed in `PROJECT_MEMORY.md`.
3. Briefly summarize recovered context when it affects the task.
4. Continue from verified project memory and logs; do not invent prior conversation details.

At the end of a meaningful task:

1. Generate an Obsidian log draft.
2. Show the target log path.
3. Ask the user to confirm before writing.
4. After confirmation, append to or create the current daily log.
5. Update `PROJECT_MEMORY.md` only when status, latest log path, decisions, open questions, or next steps changed.
