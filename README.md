# codex-journal

Codex Journal is a local Codex plugin for automatic project memory.

It generates and maintains project-local `PROJECT_MEMORY.md`, updates project `AGENTS.md`, and records meaningful Codex work into Obsidian daily project logs.

## What It Does

- Stores global settings in `~/.codex-journal/config.json`.
- Initializes projects from analysis, not manual Markdown editing.
- Creates Obsidian project folders and daily logs automatically.
- Restores project context from `PROJECT_MEMORY.md` and the latest Obsidian log.
- Records task progress automatically at task completion, respecting confirmation settings.

Default write policy:

```json
{
  "require_confirmation_before_write": true
}
```

With this default, Codex drafts the log entry and asks before writing.

## Initialize Global Config And A Project

From any project root, run:

```bash
python3 /path/to/codex-journal/scripts/init_project_journal.py \
  --project-root . \
  --vault "/absolute/path/to/Obsidian"
```

This creates or updates:

- `~/.codex-journal/config.json`
- `<project>/AGENTS.md`
- `<project>/PROJECT_MEMORY.md`
- `<vault>/Projects/<project-slug>/YYYY-MM-DD.md`

After the global config exists, later projects can omit `--vault`:

```bash
python3 /path/to/codex-journal/scripts/init_project_journal.py --project-root .
```

## Restore Context

Codex should follow the project `AGENTS.md` section generated by the initializer. To resolve context deterministically:

```bash
python3 /path/to/codex-journal/scripts/resolve_project_context.py --project-root .
```

The command prints JSON containing the generated project memory and latest Obsidian log text.

## Record A Task

Codex should prepare this automatically at the end of meaningful work. To append after confirmation:

```bash
python3 /path/to/codex-journal/scripts/append_obsidian_log.py \
  --project-root . \
  --confirmed \
  --summary "Implemented project journal initialization" \
  --change "Generated PROJECT_MEMORY.md and Obsidian daily log" \
  --next-context "Read PROJECT_MEMORY.md before continuing"
```

To preview the draft without writing:

```bash
python3 /path/to/codex-journal/scripts/append_obsidian_log.py \
  --project-root . \
  --summary "Preview entry" \
  --print-draft
```

## Update Project Memory

Codex should update project memory when task results change status, decisions, open questions, or next steps:

```bash
python3 /path/to/codex-journal/scripts/update_project_memory.py \
  --project-root . \
  --status "Current project status" \
  --decision "Confirmed decision" \
  --next-step "Next concrete step"
```

## Hooks Status

The repository includes `hooks/` documentation for the intended lifecycle integration, but `.codex-plugin/plugin.json` does not declare hooks yet. The current local plugin validator rejects unsupported manifest fields such as `hooks`, so scripts are the stable command surface for now.
